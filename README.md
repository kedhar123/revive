# Revive App - How It Works Page

A beautiful Next.js application showcasing how the Revive App works with a three-step process for eco-aware food insights.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Clean, professional design with smooth animations
- **Three-Step Process**:
  1. Take a Photo - Snap pictures of products with your camera
  2. Data Analysis & Validation - AI-powered analysis with verified databases
  3. Actionable Insights - Personalized recommendations and alternatives

## Tech Stack

- **Next.js 15** - React framework with App Router
- **Tailwind CSS 4** - Utility-first CSS framework
- **JavaScript** - Modern ES6+ features
- **Responsive Design** - Mobile-first approach

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn package manager

### Installation

1. Install dependencies:

```bash
npm install --legacy-peer-deps
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
